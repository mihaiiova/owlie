## [0.1.0] - 2026-08-21

### Added

- Monorepo scaffold (pnpm workspaces, TypeScript, Vitest, ESLint, Prettier).
- `@owlieio/core` contracts: types, adapters, transcriber, processor, progress,
  output serialization, bounded collection limits, orchestration helpers, and a
  typed error hierarchy (including `CaptionsUnavailableError`).
- `owlie extract` — extract a transcript from an individual YouTube video via
  the pure-JS `@hallelx/youtube-transcript` library (no Python required), with
  URL recognition/canonicalization, language selection (`--language`),
  cancellation/timeouts, and typed errors.
- `owlie extract` — universal item dispatch: a direct URL is routed to the
  YouTube or static-article adapter by the registry, and a recognized RSS/Atom
  feed URL triggers a bounded linked-item batch extraction into a single JSON
  envelope (`collection`, `items`, `truncated`) with per-item structured
  errors, `--limit` bounds (default 10, maximum 500), and exit 1 on partial
  failure.
- `owlie list FEED_URL [--limit N] [--json]` — list bounded entries of an
  RSS/Atom feed via `@owlieio/adapter-rss`, with a line-oriented summary or a
  single JSON envelope, `--limit` bounds (default 10, maximum 500), and typed
  error/exit-code mapping.
- `owlie process` — process plain text or a normalized document with DeepSeek,
  reading from a file, `--input`, or stdin; model selection via `--model` and a
  provider registry.
- `owlie process FEED_URL --each [--limit N] --prompt "..."` — process the
  bounded linked items of an RSS/Atom feed sequentially in feed order,
  dispatching extraction through the universal YouTube/article rule and
  streaming one JSONL record per attempted item (success:
  `item`/`document`/`result`; failure: `item`/`error` with an `extraction` or
  `processing` stage). Retains successful items, exits 1 on partial failure,
  and bounds the batch with `--limit`.
- `owlie setup` — guided interactive configuration of provider, model, API key,
  and (optionally) a WebShare or generic proxy for YouTube transcript fetching,
  persisted to `~/.config/owlie/config.json` and used as the default by future
  `process`/`extract` invocations.
- `@owlieio/provider-deepseek` — the first functional LLM provider, implemented
  with `ai` and `@ai-sdk/deepseek` (`deepseek-chat` default model).
- Pipe-first CLI contract: stdout = result only, stderr = diagnostics/progress,
  typed exit codes, `--json`, `--input-format json`, and broken-pipe handling.
- A lightweight stderr spinner animates during `extract` and `process` (suppressed
  by `--quiet`).
- `owlie doctor` reports `DEEPSEEK_API_KEY` presence and the functional
  adapters (YouTube, RSS, article) and provider (DeepSeek).
- Adapter scaffolds for podcast, RSS/Atom, and Reddit (pure URL logic; no
  network access) and provider scaffolds for OpenAI and local faster-whisper
  (deferred).
- `@owlieio/adapter-rss` safe RSS/Atom parsing (`parseFeed`, `htmlToText`, and
  `decodeXmlEntities`) with XML entity-expansion protection: `fast-xml-parser`
  (`processEntities: false`) plus `entities`-based decoding, rejecting any
  DTD/entity declaration. Handles RSS 2.0, Atom (including Reddit's
  Atom-in-`.rss`), and RSS 1.0 (RDF).
- `@owlieio/core` safe HTTP fetch (`isBlockedHost`, `assertSafeHttpUrl`,
  `HttpFetcher`, `DefaultHttpFetcher`) with SSRF protection, redirect caps,
  timeouts, response-size limits, and an identifying User-Agent. Its bounded
  response seam exposes final validated URL and declared media type for
  adapters that need content-aware parsing.
- `@owlieio/adapter-article` — reusable static editorial-page extraction from
  bounded, safe-fetched HTML using `@extractus/article-extractor`'s HTML-only
  API; it accepts HTML/XHTML only and is registered in the CLI for universal
  `extract` dispatch.
- `@owlieio/adapter-rss` `list` (bounded feed enumeration with stable
  `rss:entry:<id>` identities and truncation) and `extract` (a single entry as a
  `mediaType: 'text'` document, preferring `content` over `description`, with a
  re-fetch fallback for items lacking carried text).
- `@owlieio/testing` fakes, fixtures, and contract-test helpers, wired into the
  YouTube item-adapter and DeepSeek processor contract tests.
- Offline unit/contract/integration/CLI/pipeline test suites; opt-in live tests
  (`OWLIE_LIVE_TESTS=1 pnpm test:live`).
- Packaged-artifact verification (`pnpm verify:artifact`) on macOS and Linux CI.
- Architecture, contracts, security, migration, and decision documentation
  (including ADR 0005 — v0.1 scope).

### Changed

- `owlie --help` and `owlie doctor` now list only the functional surface
  (YouTube and RSS adapters, DeepSeek provider). Deferred adapters, providers,
  and commands are no longer exposed in help or doctor output.

### Fixed

- Static article extraction no longer drops article bodies that Readability
  keeps inside a `<main>` (or other semantic) wrapper. The article adapter now
  passes an explicit `allowedTags` allowlist to
  `@extractus/article-extractor`, whose sanitizer otherwise removes a
  disallowed element together with its subtree.

### Deferred (not yet implemented)

- Collection search (`search`) and `config`.
- RSS/Atom entry extraction via the CLI (the adapter's `extract` remains
  library-only); Whisper/audio transcription; podcasts; Reddit extraction.
- OpenAI as a functional provider.
- Scheduling, monitoring, cron, a local database, and persistent job records.
