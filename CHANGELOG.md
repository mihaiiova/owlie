## [Unreleased]

### Added

- Monorepo scaffold (pnpm workspaces, TypeScript, Vitest, ESLint, Prettier).
- `@owlieio/core` contracts: types, adapters, transcriber, processor, progress,
  output serialization, bounded collection limits, and orchestration helpers.
- Adapter scaffolds for YouTube, podcast, RSS/Atom, and Reddit (pure URL logic;
  no network access).
- Provider scaffolds for OpenAI (content processor) and local faster-whisper
  (transcriber).
- `@owlieio/testing` fakes, fixtures, and contract-test helpers.
- `@owlieio/cli` with functional `--help`, `--version`, and `doctor`.
- CI (GitHub Actions), issue templates, and pull request template.
- Architecture, contracts, security, migration, and decision documentation.

### Not yet implemented

- Real content extraction, transcription, search, or LLM processing.
